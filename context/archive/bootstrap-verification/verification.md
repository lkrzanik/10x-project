### Why this stack

ASP.NET Core MVC na Azure App Service to naturalny wybór dla single-user internal tool w ekosystemie .NET. Silne typowanie C#, konwencyjny układ MVC i doskonała dokumentacja Microsoft zapewniają wysoką produktywność agenta AI i solo-developera. Azure SQL Database pokrywa potrzeby persystencji bez nadmiarowej złożoności. Azure DevOps Pipelines (YAML) z repozytorium GitHub daje CI/CD natywnie zintegrowane z targetem deploymentu.
